# Procedure VM-02: Vendor bank detail change requests

Requests to change a vendor's bank account are a common payment fraud. Never change bank details because of an
email, ticket or phone call. Changes need a verified callback to the phone number already on file, done by the
vendor master team.

## Action
Do not update the bank account. Escalate to the vendor master team with the request details.
Never read back the bank account currently on file to the requester.
